# Week 1 — C# Practice

This week I practiced creating a Windows Forms application using Visual Studio.

### Form
The Form is the main area where I designed the application and placed the controls.

### Solution Explorer
I used Solution Explorer to view and manage the files and components of my project.

### Properties
I used the Properties window to customize the controls, such as changing their text, size, and other settings.

### Toolbox
I used the Toolbox to select and add the controls needed for my Windows Form.

- **Label:** Used to display text or information on the Form.
- **TextBox:** Used to allow the user to enter text or information.
- **Button:** Used to allow the user to perform an action by clicking it.
